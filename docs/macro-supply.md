# 宏观接口、时间序列与修订记录

2026-11-14 核验当前发布的两项产品。宏观传导和宏观洞察共同指向 `20261108-366f83bfc727036c`，业务可见时刻为 2026-11-08 14:51:37 UTC。两个产品各有 58 个版本，同一版本能同时取到两份正文；业务时刻共 55 个，范围从 2026-08-24 至 2026-11-08。 [逐系列来源、取版规则、最新原件 ID 和对账结果](research/investmind-macro-supply.json)

## 接口与页面

| 底座接口 | 请求与响应 | InvestMind 用途 |
|---|---|---|
| `GET /api/v1/macro/transmission` | 可选 `version` 和 `view=full/initial/scope`。初始视图从 `enterpriseAnalysis` 中省略 `industryComparison`、`officialTargets`，按同版再读 `scope`，只返回 `enterpriseAnalysis.inputHash/industryComparison/officialTargets`。旧版无企业分析时返回 `enterpriseAnalysis=null`。 | 宏观传导链、分析卡、企业财报与行业/官方对照；首屏后展开企业范围可延迟取数。 |
| `GET /api/v1/macro/insights` | 可选 `version`。正文为对应版本洞察，外层 `collectionAudit` 为读取当时的采集状态，每次请求返回 `Cache-Control: no-store`。 | 基础指标趋势、沙盘、经济罗盘、状态卡、专项观察与采集状态。 |

原有 `/api/data/macro-transmission` 和 `/api/data/macro-insights` 各与相应 v1 路径共用一个处理函数。网站先并发取当期两项，若版本不同，再指定传导的版本取洞察。历史业务字段来源为 `mart.page_snapshot`；未指定版本时读 `mart.published_snapshot`。已重放当前、显式当前版、最早历史版、不存在版本、非法参数及传导首屏、企业差量视图，逐一对比响应码和内容。不存在版本返回 404，空版本及无效视图返回 422。历史洞察带的采集状态代表当前读取时刻。

### 企业范围二次请求的实际载荷

宏观页面首次取传导首屏与洞察各一次。有企业范围数据时再按传导版本取一次范围；站内会话缓存仍以版本与企业输入哈希复用。原二次请求会重复返回整份传导，现取 `view=scope`，仅用已核对版本和相同 `inputHash` 的两个延迟字段补回首屏企业对象。以该发布版本的 HTTP JSON 响应正文计量，前后均为两次传导读取；另有独立的一次洞察读取。

| 传导响应 | JSON 字节 | 相同 gzip 编码下的字节 |
|---|---:|---:|
| 首屏 initial | 3,117,095 | 344,164 |
| 原二次读取 full | 16,511,553 | 1,743,819 |
| 当前二次读取 scope | 13,394,693 | 1,399,736 |

二次响应减少 3,116,860 个 JSON 字节（18.88%），gzip 对照减少 344,083 字节（19.73%）。完整传导仍供显式 full 请求和既有调用者使用。范围路由沿用当前的 JSON 快照读取路径；这些结果衡量从 API 发出的响应体，不等于数据库读取字节或真实网络吞吐。浏览器接收的传输字节还取决于代理压缩与缓存。

### 时间和修订

每条核心事实的观测期、披露/获知时刻、供应商、修订身份和有效截止分别记录。两份页面历史均按发布时已知版本冻结。对截至该时刻的证据，按“同系列、同供应商、同观测期”统计有 **553 组实际数值变动**，分布在美国实际 GDP、CPI、核心 CPI、核心 PCE、失业率和非农就业；每条系列保留修订组数与一组实际核心行示例。其余系列未观察到数值变动的期间不能推断供应商从未修订。抓取可见的重述历史与市场当时首发历史存在证据边界。

当前配置启用每周一 09:00（上海时间）的同步、启动追赶和十年历史窗。规划器在日/月/季频分别设置 31 日、18 月、12 季重叠窗口，结合上次观测期向当前日期推进以发现新期和近期修订。20 项中两个来源为空的系列当前采集状态为暂停。本库记录到 `sync-macro` 的 96 次任务均为 CLI 触发，其中 89 次完成、4 次部分完成、3 次失败；另外有 3 次 CLI 追赶、53 次历史回填。这里证明已有运行记录及各序列可见范围；无人值守上线后的每周触发和新期发现尚待运行证据。当前实时采集面板有 183 条状态记录，含 178 成功、2 暂停、3 失败，范围包括拓展及企业侧记录，不能作为全部系列都已更新的证明。

### 派生和扩展

- 六条利差/剪刀差按输入实际共同日期独立重算，分别为 PPI−CPI 120 点、M2−M1 120 点、M1−M2 120 点、国债−DR007 2,504 点、美债−联邦基金 2,512 点、中美利差 2,339 点。共 7,715 点全部匹配。中美利差由百分点乘 100 转基点。没有交集的日期不会向前填充。
- 两产品共用的 `extensionInsights` 逐字段相同。实际 GDP 为 40 期，名义 GDP 为 20 期；VIX 最新日期 2026-10-22，专项汇率的当前日期为空。财政债券流量窗 48 个月，有 1 份文件、45 个缺失月份，最近可用为 2022-12。另有住户信贷、房地产贷款、专项债、一线城市住房四组，以及交易所流通市值与融资余额两组。这里核到已发布范围及完整性标记，专项官方文件、逐表解析和样本推断的对账需按专题另附证据。
- 企业分析当前持有 50 股样本、6 张卡，使用 `enterprise-quarter-v7`、池版本 `2026-09-19-v2`、分析日 2026-11-08，明确采用当前池重述历史。行业对照和官方目标可在同版完整响应中获取，本项只核验版本绑定与承载范围。
