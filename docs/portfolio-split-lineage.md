# 投资组合公开输入与网站私有分析

核验数据截至 2026-10-21，底座发布版本 `20261021-690705b397d4b878`。验证组合由贵州茅台 60%、平安银行 30%、人民币现金 10% 构成，使用真实已发布行情和指定的测试配置。用户账户、成交单和个人持仓没有参与核验。

## 接口和所属项目

| 调用方与入口 | 输入和输出 | 存放位置或用途 |
| --- | --- | --- |
| 网站布局或私有分析服务 → 底座 `GET /api/v1/portfolio` | 固定路径，无用户参数，返回已发布的公共输入和发布元数据。旧 `GET /api/data/portfolio` 返回相同事实及版本，并附带旧版空持仓模板和存储键 | `mart.published_snapshot` 的 `portfolio`；两个公开 URL 上 POST 都是 405，两者的 `/analysis` 子路径都是 404 |
| 项目浏览器 → 网站 `POST /api/portfolio/analysis` → 网站私有服务 `POST /analysis` | 仅提交持仓标识与非负相对权重，以及可选窗口和基准。服务校验全部输入，按公开快照在内存中计算，响应 `no-store` | 私有服务只向底座发送固定 GET，未转发正文、Cookie、Authorization 或自定义私有头。提交额外的 `trades` 字段返回 422，底座读取为零 |
| 项目浏览器的组合配置、草稿、本金、股数和现金金额 | `portfolio-store.ts` 读写网站本域 localStorage；数量模式按共同建仓日未复权收盘价折算权重。股数、现金金额和本金不进入上述 POST | 无账户成交账本。100 股贵州茅台和 1,000 元现金在 2023-10-23 以 1,643.98 元换算为 99.395398% 和 0.604602% |

网站 `src/modules/portfolio/api.ts` 管理空持仓模板、默认参照、浏览器存储键。现有用户仍从 `danginvest:portfolio-sandbox:v1` 恢复配置，无需搬移或重写浏览器存储。只读抽查覆盖 `mart.page_snapshot` 全部 17 个历史版本及当前指针：全部同键、空持仓、3 年周期；其中 9 个历史版本无默认双基准，8 个和当前指针含 H00300.CSI 与 H00922.CSI。展示用 fixture 沿用 1 年周期。网站在两个指定全收益指数均有供给时才填入默认选择。

v1 对既有快照也剔除 `defaultState` 和 `storageKey`，新建与重建不再生产或继承这些字段。历史行保持原样，底座的旧 GET 兼容适配器继续生成这两个旧字段，持仓始终为空。本次没有触发真实重建或改写数据库，实库当前指针物理去除旧字段将在常规发布时完成。

## 窗口和数值复核

- 指定组合的 1 月、3 月、6 月、1 年、3 年、5 年及全部周期分别有 17、61、122、243、726、726、726 个实际共同观测。3 年和 5 年窗口提示起点覆盖不足。公开输入最早为 2023-10-23，无法提供完整 5 年研究。
- 全部窗口为 2023-10-23 至 2026-10-21。页面与私有服务 726 个净值逐点一致，总回报为 2.886633%。一年窗口的 243 点也逐点一致，总回报为 −2.437495%。两个全收益基准均逐日与发布收盘点位除以窗口首日点位核对。未来窗口两端均为零观测。
- 全部窗口的成本股息率为 4.380566%，TTM 为 4.523845%，平均动态为 4.281566%，NTM 模型估算为 4.330351%。三项持仓的完整分项贡献各自合计为该资产区间收益。独立计算比较覆盖净值和基准；四种股息率按网站实际转换器重放。
- 对全部 50 股逐一构造单股持仓，其各自的全历史窗口为 580 至 726 点。43 股窗口内有完整日期且两个基准可对齐；7 股存在内部缺日，页面停用日频统计，两个基准均无可对齐结果。没有使用前值填充。
- 单股成本股息率和 TTM 各有 49/50 个值，NTM 有 39/50 个值。平均动态有 50/50 个值，其中 8 股排除了未满足输入条件的日期，只能解释为可用日平均。40 股具备完整四项归因、9 股仅得到价格与股东回报拆分（6 股边界盈利非正、3 股归母净利润缺失或同版冲突）。比亚迪因撤回方案无法定位，归因不可用。每只证券的窗口、缺项原因和基准点数均存入证据。
- 纯现金目前有独立的行为差异。公开快照仅提供一个 CNY 面值点，页面在一年窗口无法取得两个自身观测，不发起分析请求。直接调用私有服务时，旧公式以市场日历输出 243 个单位净值点。两个既有测试分别固定了这两种行为；此项保留为口径未决。

## 读取次数和复核入口

四个指定的私有 HTTP 分析请求各访问一次公开 GET。第一次查询一次完整快照并传输 8,131,607 字节响应正文。后面三次只查发布指针的来源元数据，均返回 HTTP 304、正文 0 字节，SQL 未选择 payload。相较每次传输整包，这组试算少读三次数据库正文，少传 24,394,821 字节。数据库源的弱 ETag 绑定公共合同版本、发布版本、业务时间、来源、鲜度和原因。换版或鲜度变化时重取完整公开输入，读取失败时不返回缓存旧结果。旧客户端可继续无条件 GET；旧底座不带 ETag 时私有服务继续无条件读取。八个并发调用在受控回归中共享一次进行中的公开读取。

Next 布局和私有分析服务使用独立进程。冷启动首次打开页面、首次分析各自需要可信公共正文，合计两次完整读取；用户浏览器提供的版本或内容不能替代私有服务自己的底座来源。后续试算只重新验证服务内保存的一份公共快照，各用户的配置与分析结果不进入缓存。页面各标签共用本地 `result`，切换标签未列入本次 HTTP 测量。普通买入持有且不指定参考日历时才启用服务端核对，扩展策略由网站本地计算。

从独立底座运行 `backend/.venv/Scripts/python.exe -I scripts/audit-portfolio-split.py --website <网站仓目录> --output <新回执路径>`。底座协调器使用只读事务核对公共路由及 SQL 次数，以 HTTP 访问网站仓自身启动的私有服务。私有服务、页面计算和 Node 投影驱动归网站管理。逐股结果见[本次核验记录](research/investmind-portfolio-split.json)。
