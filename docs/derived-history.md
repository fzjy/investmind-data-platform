# 派生指标的留存、重算和缺口

2026-11-14 实库共有 22 个股票指标 ID、31 个“指标＋公式版本”组合。3,628 个结果行均有输入引用，共 25,905 条，均带内容哈希。[逐指标起止日期、公式版本、证券数及输入引用](research/investmind-derived-history.json)

| 指标或用途 | 当前策略及历史边界 |
| --- | --- |
| 财报及股东指标：capitalReturnRatio、cashflowGrowth、dividendYears、freeCashFlow、institutionHolding、netDebt、payoutRatio、profitGrowth、realMoneyIndex、revenueGrowth、历史 roic | 保留已产生的结果与修订输入，按财报实际公开日选择版本。普通指标只在最多 5 个业务日有历史，机构持仓先后有两版公式。选股 ROIC 现按已披露年报的百分数在读取时算，原有 ratio 结果保留。不能把账面报告期当作投资者当天可知的日期。 |
| 价格相关指标：expectedDividendYield、pePercentile、pbPercentile，以及工作台 8 张 v1/v2 指标卡 | 批量筛选和排序复用发布版本。同版展示、散点和研究页面共享结果。工作台八卡每个公式版本目前只有一个业务日；估值依赖同日股价及当时可见财报。未来按需重算须固定股价、复权、财报修订与公式版本，不能用当前已修订数冒充历史快照。 |
| 风险卡 | 带版本的风险表按证券和规则保留当前结果。12 条规则对应最新 600 行，历史工作台页不含风险卡。历史重算还需当日可见的各项原料与当时规则。已确认的早期空缺继续留空。[各规则和缺口](workbench-api.md) |
| 宏观差值、利率与企业范围 | 差值按两条输入真实共同日期重算，底层观测和页面发布版本保留。库中 derived.macro_xray_result 当前为空，已验证的 7,715 个派生点由发布产品提供。[宏观历史版本](macro-supply.md) |
| 比值沙盒、DCF 与组合用户假设 | 各项目按相同公共数据版本在本地或网站私有服务计算，持仓及参数由项目管理。可复现需要保留所用公共版本和当时用户参数。底座不保存用户每次试算的结果。[DCF 与窗口对账](research/investmind-workbench-panels.md) · [组合](portfolio-split-lineage.md) |

相同证券、指标、业务日及公式版本再次计算时，现有写入路径可更新结果和输入引用。内容哈希能检验手头原件，不单独证明每次修订的旧结果仍在。历史页保留情况、实际可见时间和原件来源须一起核对，才能确认历史重放范围。本次未修改指标保留期或删除旧数据。
