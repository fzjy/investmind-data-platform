## 按历史业务日重放

2026-11-15 对 3,628 条已留存结果，在只读事务内按证券、指标、业务日、公式版本比较数据库十位小数结果以及全部输入的名称、表、记录键、内容哈希和出现次数。先运行当前实现，再对当前实现无法执行的旧版使用拆分前 Git 归档的整个输入装载器和公式。归档只含当时的代码和跟踪配置。没有写回缺值或修订。
