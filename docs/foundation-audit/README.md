## 复跑与边界

分红专项的变体、金额、同请求异文与跨请求取值交集都从已校验的 HTTP 原字节读取。先核对字节长度、SHA-256、业务状态、分页、字段及规范块，再按十进制解析小数，逐份保留 Raw ID 和行号。常规分红缺少 HTTP 原字节时，按 PostgreSQL 保存的 JSON 文本读取小数，可重现精度以当时入库的文本为限。每份凭证所用的方法记录在 `dividends.json` 的 `businessRowsSource`。

在仓库根目录运行下列命令。脚本检查本机地址、PostgreSQL 驱动、只读事务和可重复读隔离级别，用相同事务为领域 SQL 与产品读取提供数据。文件输出在本目录，已有 `baseline.json` 保留。复跑时新的抓取或发布会产生不同的库存证据，固定基线的摘要需按同版本比较。

```powershell
backend/.venv/Scripts/python.exe -I scripts/foundation-audit.py
```

`ranges` 统计实际返回的键。缺少表格式字段、关键维度或日期的记录另计，返回交集不能证明某一请求本应返回的完整范围；非空值冲突还可能来自同一请求内部修订。这些组与分红逐笔完备条件分别处理。旧回补的最早 3 条分红原件暂不能从当前证券池与作业参数重建请求参数明文，但其请求哈希、批次、正文和时间保留，均不属于 156 条额外捕获。历史请求窗口按任务时段关联时单独标为 `overlappingRuns`。带批次 ID 的冻结游标提供了更直接的关联。只读审计不调用上游，没有执行业务库写入、采集切换或物理迁移。
