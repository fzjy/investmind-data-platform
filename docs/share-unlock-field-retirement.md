# Tushare 解禁字段停采与历史查询

2026-11-14 在数据库只读事务中扫描全部 `share_float` 原件、`core.share_unlock` 以及发布消费者。新请求合同为 `ts_code,ann_date,float_date,float_share`，用于按股回填和按公告窗口增量。接口调用频率沿用原任务，历史 Raw 和 Core 均保留。[原件与字段回执](research/investmind-share-unlock-consumers.json)

| 数据集及字段 | 去留及消费者 | 核验时的历史 |
| --- | --- | --- |
| `share_float.unlock_date` | 停止新请求。增量用 `ann_date`，截至业务日是否已解禁用 `float_date`。没有具名消费者，全列并发校验只比较实际存在的 JSON。新合同遇到供应商额外返回此字段时，保存原始响应、跳过该键的 Core 写入。 | 65 个历史响应、19,399 个返回行中均未出现该键。21 股共 82 个 Core 行也没有该键，因此无最后业务日。其他部署的旧行若已有该值，窄合同重放保留其原值。持有旧字段合同的历史回放仍按原合同解释。 |
| `share_float.float_share` | 保留采集。当前没有直接展示该解禁股数的网页。股票发布在组装与提升产品时分别读取 `corporate_actions`，`source_signature` 对可见解禁记录含 JSON 的完整内容取哈希，股数变化可阻止来源在构建期间已变的候选产品提升。调用真实发布函数，仅改变脱离数据库的股数即可得到不同签名。 | 65 个 Raw 响应共 19,399 个非空股数。82 个 Core 行都有值，覆盖 21 股，公告日 2021-06-11 至 2026-07-16。以 2026-10-21 的池和可见性检查，82 行均可进入签名。Raw 与归一后 Core 的行数分别统计，粒度及过滤范围不同。 |
| `share_float.ts_code/ann_date/float_date` | 保留证券、公告日、实际解禁日。增量的公司行为标的按公告日发现，快照按证券、公告日与实际解禁日检查可见性，发布来源标识也用这三个字段。 | 82 行均有三项。以 `ts_code,ann_date` 查 Core 行，以 `raw.source_payload.api_name='share_float'` 定位原件。回执保留各批次请求哈希、内容哈希、时间和实际返回列。 |
